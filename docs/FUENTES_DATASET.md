# Fuentes reales para el dataset de Machine Learning

## Objetivo

Documentar las fuentes reales candidatas para construir la semilla de datos del sistema My Ganado. Durante la primera etapa se prioriza la verificación de procedencia, calidad, licencias y relación con bovinos.

## Criterios de selección

Se evaluará cada dataset con base en:

- fuente y institución responsable,
- fecha de publicación,
- cantidad de registros,
- variables involucradas,
- unidades de medida,
- calidad de los datos,
- presencia de faltantes o duplicados,
- licencias y condiciones de uso,
- relación con bovinos o condiciones de salud animal,
- posibilidad de apoyar la variable objetivo derivada o directa.

## Fuentes candidatas

### 1. FAOSTAT / FAO

- Tipo: estadísticas agropecuarias internacionales.
- Uso potencial: variables relacionadas con producción y salud bovina a nivel regional.
- Fortalezas: fuente institucional confiable.
- Limitaciones: no siempre ofrece datos a nivel individual o fisiológico.

### 2. ICA (Instituto Colombiano Agropecuario)

- Tipo: datos oficiales y estadísticas del sector ganadero colombiano.
- Uso potencial: contexto animal, producción, sanidad y seguimiento regional.
- Fortalezas: cercanía al contexto nacional.
- Limitaciones: el nivel de detalle puede requerir integración y preparación.

### 3. UCI Machine Learning Repository

- Tipo: repositorio académico de datasets.
- Uso potencial: datasets de animales y salud animal si se encuentran verificables.
- Fortalezas: fuente conocida y pública.
- Limitaciones: se debe validar la metodología y la procedencia exacta.

### 4. Zenodo / Mendeley Data / repositorios científicos

- Tipo: datasets publicados por investigación o universidades.
- Uso potencial: variables fisiológicas o de comportamiento bovino.
- Fortalezas: útil para datos de investigación y etiquetado.
- Limitaciones: requiere extraer la documentación y validar calidad.

## Requisitos para la fuente final

La fuente definitiva debe cumplir al menos:

- procedencia verificable,
- datos reales y no puramente simulados,
- variables relevantes para bovinos,
- documentación suficiente de la recolección,
- uso permitido y claridad de licencia,
- calidad adecuada para limpieza reproducible.
